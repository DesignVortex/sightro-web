# Sightro

Sightro is a suite of web experiences designed to turn a passive property website into an active discovery journey for buyers.

## Development

This project uses Tailwind CSS v4 and GSAP for animations.

### Requirements
- Node.js

### Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

### Building for Production
Run `npm run build` to generate the final optimized CSS.
